Thanks for your interest in contributing to Macros! This document explains the
licensing terms that apply to every contribution.

By submitting a contribution to this project (for example, by opening a pull
request, sending a patch, or otherwise providing code, documentation, or other
material), you agree that:

1. **You license your contribution under the MIT License.** Your contribution,

2. **You have the right to license it.** The contribution is your original work,

   rights.

3. **You certify the Developer Certificate of Origin.** Your contribution
   complies with the [Developer Certificate of Origin](https://developercertificate.org/)
   (reproduced below).

If you cannot agree to these terms, please do not submit a contribution.

## Developer Certificate of Origin

To certify the above, add a `Signed-off-by` line to your commit messages:

```
Signed-off-by: Your Name <your.email@example.com>
```

Git can add this automatically with the `-s` flag:

```
git commit -s -m "Your commit message"
```

## Third-Party Code

If your contribution includes code you did not write (for example, a vendored
library or a snippet from another project), it must be compatible with the MIT
License, and you must clearly attribute it and note its license. Add the
relevant license information to [`THIRD-PARTY-LICENSES.md`](THIRD-PARTY-LICENSES.md).
