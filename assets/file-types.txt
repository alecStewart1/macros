# File extensions Macros registers with the OS as an "Open With" handler — never
# the default. One lower-case extension per line, no dot; `#` starts a comment.
#
# Consumers:
#   macOS   scripts/build_macos.sh turns this into Info.plist's
#           CFBundleDocumentTypes at bundle time.
#   Windows wix/file-types.wxi (OpenWithProgids + SupportedTypes), generated from
#           this file. Regenerate after editing:
#             UPDATE_FILE_TYPES=1 cargo test os_file_associations
#   Linux   assets/linux/macros.desktop lists MIME types, not extensions; keep
#           its MimeType= line roughly in step by hand.
#
# A test (highlight::tests::os_file_associations_cover_bundled_languages) fails
# if a bundled grammar's or the grid's extension is missing here, or if the
# .wxi is stale.
